# Plataforma Educativa: Trafkintu Kimün (Intercambio de Saberes)

## Problemática
La falta de un espacio articulado para el intercambio recíproco de saberes (Trafkintu Kimün) entre las 
comunidades escolares de Temuco y Puerto Saavedra invisibiliza el gran valor ecológico y cultural de sus 
humedales locales. Esta desconexión limita las oportunidades de fortalecer la educación ambiental, el sentido 
de pertenencia territorial y el desarrollo del bienestar comunitario conjunto de los estudiantes.
